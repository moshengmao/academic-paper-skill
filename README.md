# Academic Paper Skill 📚

An AI Agent skill designed to help researchers and students efficiently structure, summarize, and analyze academic papers.

## 🎯 Core Features
- **Structured Extraction**: Automatically extracts research background, methodology, and key results from PDFs or text.
- **Presentation Outline**: Generates PPT outlines suitable for group meetings or seminars.
- **Critical Analysis**: Identifies limitations and future research directions.

## 🛠️ How to Use
Simply import the `SKILL.md` into your AI agent workflow. When you upload a paper, the agent will follow the defined SOP to process it.
